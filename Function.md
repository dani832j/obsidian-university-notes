### Definition

Let $A$ and $B$ be sets.

A function $f$ from $A$ to $B$ is a rule that assigns

to every element $A \in a$ a unique element $f(a) \in B$.

We write

$$

f : A \to B.

$$
___
### Example

Define

$f : \mathbb{R} \to \mathbb{R}$ by $f(x)=x^2.$

Then

$f(2)=4,$ $f(-3)=9.$

Each input has exactly one output, so $f$ is a function.

### Notes

A function describes how outputs depend on inputs.

For every allowed input, there is exactly one output.
