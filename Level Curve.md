### Definition

Let

$f(x,y)$

be a function of two variables.

A level curve is the set of all points $(x,y)$ satisfying

$f(x,y)=k$

for some constant value $k$.
___
### Example

Let

$f(x,y)=x^2+y^2$

Find the level curve for

$k=1.$

We solve

$x^2+y^2=1.$

This is a circle with radius 1 centered at the origin.

### Notes

A level curve consists of all points where the function has the same value.

You can think of level curves as contour lines on a topographic map:

- Every point on the same curve has the same height.

- Different curves correspond to different heights.

Level curves allow us to visualize a 3D surface using a 2D drawing.
