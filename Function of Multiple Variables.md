### Definition

A function of multiple variables is a [[Function]] whose input consists of two or more variables.

Formally. 
$$
f:D \to \mathbb{R},
$$
where
$$

D \subseteq \mathbb{R}^n.

$$
For every point
$$

(x_1,x_2,\ldots,x_n)\in D,

$$
the function assigns a unique real number.
___
### Example

Let
$$

f(x,y)=x^2+y^2.

$$
Then
$$

f(1,2)=1^2+2^2=5.

$$
The input consists of two variables, so this is a function of multiple variables.

### Notes

A function of one variable takes a single input.

A function of multiple variables takes a point as input.

For example:
$$
f(x)=x^2
$$
takes a number as input, while
$$
f(x,y)=x^2+y^2
$$
takes a point in the plane as input.
