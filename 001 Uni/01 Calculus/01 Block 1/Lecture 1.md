## Key Idea 1: Functions of Multiple Variables

A function of n variables maps

$$f: D \to R$$
Where $$D \subseteq R^n$$
A point in D has the form

$$(x_1, x_1, ..., x_n)$$

---

## Key Idea 2: Domain

The domain consists of all inputs for which the function makes sense. 

Examples:

$$\sqrt(x) \to x \geq 0$$
$$\frac{1}{x} \to x \neq 0$$
For functions of two variables the domain becomes a region in the plane.

---

## Key Idea 3: Graphs and [[Level Curve]]

For a function

$$f(x,y)$$
The graph consists of point

$$(x,y,f(x,y))$$
in  $R^3$

Level curves are obtained by solving

$$f(x,y)=k$$
for different values of k.

___

## Key Idea 4: Partial Derivatives

$$\frac{\partial{f}}{\partial{x}}$$
measures change in the y-direction.

To compute:

- Treat y as a constant when differentiating with respect to x.
- Treat x as a constant when differentiating with respect to y.
